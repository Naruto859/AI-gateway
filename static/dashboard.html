Idle before probe
Seconds of silence before keepalive probes start.
sec
Probe interval
Gap between each probe.
sec
Probe count

Rotation

Switch IPs when one fails.

Auto rotation
OFF = use one pinned proxy (all retries same IP). ON = rotate across enabled proxies when one fails.
Dedicated proxy
Single IP used when rotation is OFF. Add this exit IP to agentrouter watchlist.

Hot Pool Engine

Pre-verified fast proxies kept in memory for instant use. Reduces latency dramatically.

Hot Pool
ON = keep a pool of verified proxies in memory, refresh periodically. OFF = use DB proxies directly (for premium/paid proxies).
Pool size
Number of verified proxies to keep ready in the hot pool.
Refresh interval
How often to re-test and refresh the hot pool.
sec
Test timeout
Timeout for background tests. Higher finds more free proxies, lower finds faster ones.
sec
Testing Concurrency
Max candidates to test in parallel during refresh (limits CPU / event loop load).

Active Proxy Scanner

Fast background TCP tester. Accurately finds live proxies from imported/unknown lists.

Proxy Scanner
ON = constantly test new proxies in the background to build a massive verified pool. Works even if Hot Pool is OFF.
Scan interval
Seconds to wait between testing batches.
sec
Batch size
Number of unknown proxies to test per batch.

Proxy Engine Settings

Global proxy testing and connection tuning.

API testing
ON = deep test proxy using API endpoint. OFF = basic TCP ping (very fast).
Hedging Concurrency
Number of proxies to race in parallel for ZERO latency. (Higher = faster, but uses more proxy bandwidth).
Connect timeout
Set under Timers → Advanced Timings. Lower = a dead proxy fails faster and the next one is tried sooner.
