Timeouts

How long the gateway waits before giving up on the upstream.

Read timeout
Max time to wait for the model's response. Long generations need a wide window.
sec
Connect timeout
Time allowed to establish the proxy connection before failing.
sec
Max retries
How many attempts per request before returning an error.

Retry backoff

Spacing between retries — keeps the WAF from seeing a burst (Claude-Code style).

Initial delay
Wait before the 1st retry. Doubles each time (1 → 2 → 4 → 8s).
sec
Max delay
Cap on the backoff wait so it never grows unbounded.
sec

TCP keepalive

Keeps the proxy tunnel alive while the model "thinks". Stops idle-drops.

Idle before probe
Seconds of silence before keepalive probes start.
sec
Probe interval
Gap between each keepalive probe.
sec
Probe count
Total probes. Coverage = idle + interval × count ≈ 15 min.

Rotation

Switch IPs automatically when one gets blocked or slow.

Auto rotation
OFF = always use the one pinned proxy. ON = rotate across all enabled proxies when one fails (WAF / timeout / 503).
Dedicated proxy
The single IP used when rotation is OFF. Add this IP to your provider's watchlist.
